# 在场 · Her / His

一个 macOS 语音陪伴原型。默认名字“小禾”：你开口，她回应；不聊天时安静等待。当前版本 **0.3.5**，支持 Apple Silicon、macOS 14 及以上。

## 体验与功能

- 原生 SwiftUI 界面，支持语音、文字、本机名字唤起。
- 豆包端到端实时语音、OpenAI 实时语音，以及 Ollama 本机对话。
- 本机模式可用系统声音或 ElevenLabs；云端服务需自行开通并配置密钥。
- 自动筛选个人事实、偏好和边界；可查看、编辑、删除和关闭记忆。
- 实时对话携带最多 20 条记忆，使用本机关键词、中文词组及有限同义主题检索相关内容，并优先保留本会话最近保存项。新记忆保存后更新当前连接，收到服务端确认后显示“记忆已同步当前对话”，无需重新开启。
- 尽量少追问、少说教，尊重“先听我说”，也能温和表达不同意见。模型表现仍需实际验证。

## 本机构建

需要 Swift 6 工具链、Xcode Command Line Tools；网页音频桥测试需要 Node.js。

```sh
swift test
node --test Tests/RealtimeWebTests/*.test.cjs
swift run CompanionProbe --quality
bash scripts/build-app.sh
open build/HerHis.app
```

`CompanionProbe` 使用合成输入及临时数据，不读取真实记忆或开启麦克风。依赖 Ollama 的探针需要本机已运行 `qwen3:4b`。

打包前，在 `HERHIS_SIGNING_IDENTITY` 或 `~/.config/herhis/signing-identity` 配置自己的持久代码签名证书 SHA-1。脚本拒绝临时签名，避免每次升级改变钥匙串授权身份。证书和私钥不进入仓库；面向公众分发仍需适当的开发者签名与公证。本仓库 Release 提供源码，不附带个人签名的本机安装包。

## 使用

1. 打开应用，在“相处设置”选择服务。豆包需要语音服务的 App ID 和 Access Token；OpenAI、ElevenLabs 使用各自 API Key。设置页提供官网入口。
2. 在应用安全输入框保存凭据，仅存 macOS 钥匙串。不要把 Key 写入源码或提交到 GitHub。
3. 授予麦克风和本机语音识别权限，直接开启对话，或开启本机等待后叫“小禾”。
4. 本机模式需要已安装的 Ollama 和本地模型；应用可自动准备本机服务，不自动安装或下载模型。
5. 静音、结束及关麦可停止会话；修改或删除记忆会关闭旧实时上下文。

应用必须保持运行、Mac 保持唤醒。退出、关麦或休眠后无法通过名字唤起。当前使用本机语音识别检测名字，不是低功耗硬件唤醒词引擎。

## 当前对话里的记忆

新记忆在本机保存成功后同步到当前实时会话。豆包在识别过程中提前检索；文字问题需要等相关上下文更新确认后才发送。同步不会触发额外回应或重连。

音频回复由服务端实时生成，更新到达前已开始生成的一句不会中断重说。关键词检索不等同于完整语义理解；未命中的表达仍可能需要澄清。若同步超时，会显示“未确认”，语音继续；等待中的文字不会用旧上下文自动发出，输入框为空时恢复该文字。若需发送文字，可重新开启会话后重试。删除、编辑、关闭记忆仍关闭原会话，避免继续使用旧内容。

## 数据与隐私

- 云端实时对话会传送音频及启用的记忆上下文；云端声音会传送待朗读文字。服务端保留规则由供应商和账号设置决定。
- 本机等待唤醒使用设备上的语音识别，不支持时不会偷偷改用云端识别。
- 记忆存于 `~/Library/Application Support/HerHis/`，文件权限 0600，并非额外的应用级加密。
- 默认不保存完整聊天或录音。可选“本机测试记录”会保存对话文字及诊断事件；可关闭和清空，追加时清理超过 7 天的记录，最多保留 1000 条。不记录原始音频。
- 删除记忆后保留主题/内容哈希，防止同一条自动写回；明确要求重新记住并提供新证据可恢复。语义改写和模型判断仍有局限。
- 本仓库仅包含源码、合成测试、图标和构建/发布工具，不包含真实测试聊天、个人记忆或服务凭据。

## 版本发布

```sh
python3 scripts/publish-github.py             # 检查已提交的公开源码快照
python3 scripts/publish-github.py --publish   # 推送源码、版本标签和 Release
```

发布前需可用的 GitHub CLI 登录及官方 Gitleaks 扫描器（PATH 或 `GITLEAKS_BIN`）。发布使用独立 Git 历史和 GitHub noreply 邮箱，不会推送本地私人开发历史。每个版本保留唯一标签，已发布版本不覆盖。

## 验证范围

0.3.5 通过 114 项 Swift、11 项语音桥 JavaScript 和 4 项发布工具测试，覆盖会话内记忆更新、确认、超时、停止和连续保存。本机合成场景覆盖记忆误存、跨轮倾听及基本回忆；提示词和自动测试不能代替云端听感、外放回声、自然插话、长时待机与设备切换的实际验收。本版本的云端语音回忆效果仍待真实试聊确认。
